A multi-site enterprise network designed and simulated using Cisco Packet Tracer.

## Overview & Architecture
- **Infrastructure Devices:** Cisco 2911 Routers, Cisco 2960-24TT Switches, Access Points[cite: 1].
- **Addressing Plan:** Structured IPv4 addressing scheme using CIDR/subnetting for distinct organizational units (POS/Self-service, Store Operations, HR, Executive, Office staff)[cite: 1].
- **Network Services:** Inter-router routing, DHCP server configuration, wireless access, and multi-device LAN connectivity (PCs, Laptops, Printers, POS systems)[cite: 1].

## How to Test
1. Download and install **Cisco Packet Tracer**.
2. Clone or download this repository.
3. Open `Enterprise_LAN_Topology.pkt` in Packet Tracer.
